A small program that writes one sentence, at most 200 characters, about the best meal ever had: mie ayam from a street cart on a rainy night in Bandung. The sentence names the dish and the place, and holds one specific moment, the broth, the springy noodles, and steam fogging the glasses.

## Run it

```sh
node main.ts
# writes the sentence to /output/entry.txt
```
